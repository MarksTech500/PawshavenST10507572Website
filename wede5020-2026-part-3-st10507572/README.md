**Pawshaven Website (Part 2)**


**Project Overview**

The Paws Haven Animal Rescue Website is a multi-page website developed as part of an academic web development assignment at IIE Emeris. The website was created using HTML5 and CSS3, with the primary purpose of providing information about an animal rescue organisation, showcasing animals available for adoption, and allowing visitors to contact the organisation.

The website was developed to demonstrate an understanding of web development principles, including semantic HTML, external CSS styling, website navigation, responsive design, and user experience principles.

Part 2 of the project focused on improving the website's visual presentation, implementing responsive layouts, maintaining consistent styling across all pages, and testing the website on different screen sizes.


**Purpose and Features**

**Purpose:**

The main goal of Paws Haven is to create an accessible and user-friendly online platform where visitors can learn about the animal rescue organisation, explore animals available for adoption, and access contact information.

**Key Features:**

- Feature 1: Home Page – Introduces Paws Haven Animal Rescue and provides visitors with an overview of the organisation.
- Feature 2: About Us Page – Provides information about the organisation, its mission, and its commitment to animal welfare.
- Feature 3: Animals Page – Displays animal profiles with images and relevant information to help visitors explore potential adoption opportunities.
- Feature 4: Contact Page – Provides contact information and a contact form layout for visitors who wish to communicate with the organisation.
- Feature 5: Navigation Menu – Allows visitors to move between the different website pages.
- Feature 6: Responsive Layout – Adjusts the website's layout and content presentation to accommodate desktop, tablet, and mobile screen sizes.
- Feature 7: Consistent Branding – Uses the Paws Haven logo, colour scheme, and styling throughout the website.

These features aim to provide an informative and visually consistent experience while making the website accessible across different devices.

---

**Design Considerations**

The design of the Paws Haven Animal Rescue Website was based on the following key considerations:

1. User Experience (UX): The website was designed to provide intuitive navigation and clear information, allowing visitors to access important content easily.

2. Visual Consistency: A consistent green and cream colour scheme, typography, logo, and layout were used to establish a recognisable identity across the website.

3. Responsiveness: CSS media queries were implemented to adapt the website layout to different screen sizes, improving usability on desktop, tablet, and mobile devices.

4. Simplicity: The design focuses on presenting essential information without unnecessary visual clutter.

5. Accessibility and Readability: Appropriate text sizing, spacing, image presentation, and navigation styling were considered to improve readability and usability.

6. Maintainability: An external CSS stylesheet was used to manage the website's styling centrally, making it easier to update and maintain.


**Part 2 involved enhancing the existing Paws Haven website by improving its visual design, layout, responsiveness, and consistency.**

**The following improvements were implemented:**

- Updated the website's styling using CSS.
- Improved the layout and spacing of website sections.
- Applied a consistent colour scheme across all pages.
- Integrated the Paws Haven logo into the website's branding.
- Improved the navigation menu and link presentation.
- Expanded the Animals page with additional animal profiles and images.
- Implemented responsive breakpoints using CSS media queries.
- Adjusted content and image sizing for different screen dimensions.
- Reviewed the website's usability and visual consistency.

These changes helped improve the overall presentation and usability of the website.


**CSS Overview***

The website uses an external CSS stylesheet to control the visual presentation and layout of the HTML pages.

**The CSS implementation includes:**

- CSS Variables: Used to define reusable colours such as green, dark green, and cream, ensuring consistency throughout the website.
- Typography: Controls font styles, sizes, weights, and spacing to improve readability.
- Navigation Styling: Provides consistent navigation presentation and interactive hover effects.
- Layout Management: Uses CSS layout techniques, including Flexbox and Grid where applicable, to organise website content.
- Image Styling: Controls image dimensions, positioning, and presentation to maintain a balanced layout.
- Buttons and Links: Provides consistent styling for interactive elements.
- Spacing and Alignment: Uses margins, padding, and alignment properties to create a clean and organised interface.
- Responsive Media Queries: Adjusts the layout and presentation according to different screen widths.

The use of an external stylesheet improves maintainability by allowing styling changes to be applied across multiple pages without duplicating CSS code.


**Responsive Design Overview**

Responsive design was implemented to ensure that the Paws Haven website remains functional and visually appealing across different devices.

CSS media queries were used to modify layouts according to screen width.

**Desktop View: 1024px and Above**

- Displays the full desktop navigation layout.
- Uses wider content sections to make effective use of available screen space.
- Displays animal profiles in multiple columns where appropriate.
- Maintains consistent spacing and alignment.
- Provides a structured presentation of text and images.

**Tablet View: 768px to 1023px**

- Adjusts content widths to fit medium-sized screens.
- Reduces the number of columns where necessary.
- Modifies spacing and alignment to prevent content from appearing crowded.
- Resizes images to fit the available space.
- Maintains readable text and accessible navigation.

**Mobile View: 767px and Below**

- Adapts the layout for smaller screens.
- Uses a single-column content arrangement where appropriate.
- Adjusts navigation and spacing for mobile viewing.
- Ensures images fit within the screen width.
- Improves text readability through appropriate sizing and spacing.
- Prevents horizontal overflow.

These responsive adjustments allow users to navigate and interact with the website comfortably, regardless of their device.

**Challenges and Learnings**

During the development of Paws Haven, several challenges and learning opportunities were encountered.

**Challenge 1: Responsive Layout Implementation**

Adapting the website layout to different screen sizes required careful adjustment of CSS properties and media queries.

Solution: CSS breakpoints were used to modify the layout, spacing, and content arrangement for desktop, tablet, and mobile screens.

**Challenge 2: Maintaining Consistent Styling**

Ensuring that all website pages shared the same visual identity required consistent styling of navigation, colours, typography, and branding.

Solution: An external CSS stylesheet and reusable CSS variables were used to maintain consistency and simplify future updates.

**Challenge 3: Image Presentation**

Displaying multiple animal images without disrupting the website layout required attention to image sizing and positioning.

Solution: CSS image properties were used to control dimensions and maintain a balanced presentation.

Through these challenges, I improved my understanding of HTML, CSS, responsive web design, debugging, website organisation, and version control.
